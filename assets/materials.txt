# Werkstatt – Materialien
#
# Jedes Material ist ein Abschnitt [material <name>]. Der Name ist der Befehlsname (englisch, klein, ohne Leerzeichen),
# z. B. "new box steel 10 10 10". Neue Materialien einfach unten anhängen; fehlende Werte nehmen den Standard
# (siehe docs/13-Materialien.md). Zahlen mit Punkt. "none" schaltet etwas ab (schmilzt nicht, brennt nicht ...).
# Im Spiel: Menü Ansicht -> Materialien (bearbeiten, neu, speichern) oder Befehle "materials ...".
#
# ALLGEMEIN
#   label               Name in den Menüs (deutsch)
#   aliases             weitere Namen für Befehle und alte Szenen
#   class               wood | metal | stone | rubber | plastic   Verhalten: Reibung, Verschleiß, Nägel/Dübel,
#                       Faser (Holz spaltet), Gummi federt zurück, Pfützenhöhe ...
# AUSSEHEN
#   texture             wood | brick | metal | stone | rubber | concrete | plastic | plain   Muster im Shader
#   color, color2       Grundfarbe und zweite Farbe (Maserung, Sprenkel), r g b linear 0..1
#   roughness           0 spiegelglatt .. 1 matt
#   metallic            0 Nichtmetall .. 1 Metall
#   temper              none | steel | copper   Anlauffarben nach dem Erhitzen
# MECHANIK
#   density             kg/m³
#   friction            Haft- und Gleitreibung (gegen gleiches Material, Paare unten)
#   rolling             Rollreibungszahl c_rr
#   restitution         Stoßzahl: 0 plastisch .. 1 elastisch
#   tensile             Zugfestigkeit MPa
#   compressive         Druckfestigkeit MPa
#   young               E-Modul GPa
#   hardness            Brinell-Härte MPa (Holz quer zur Faser): Abrieb, Dellen, Werkzeug-Aufprall
#   fracture_energy     Bruchenergie beim Aufprall J/m² Bruchquerschnitt (spröde ~3000, Holz 40000, Metall 5e7)
#   split_energy        Spaltenergie für einen Keil J/m², none = spaltet nicht
#   bend_radius         kleinster Biegeradius innen in Vielfachen der Dicke, none = nicht biegbar (spröde)
# WÄRME
#   conductivity        Wärmeleitfähigkeit W/(m·K)
#   specific_heat       spezifische Wärmekapazität J/(kg·K)
#   emissivity          Emissionsgrad 0..1 (Wärmestrahlung)
#   melts_at            Schmelzpunkt °C, none = schmilzt nicht
#   latent_heat         Schmelzwärme J/kg
#   puddle_height       Höhe einer Pfütze aus der Schmelze, mm
#   soft_from           ab hier sinken Festigkeit und Härte, °C
#   half_strength_at    hier ist nur noch die halbe Festigkeit übrig, °C
#   brittle_below       darunter spröde (Kälte), °C, none = wird nie spröde
#   chars_from          ab hier verkohlt/zersetzt es sich (wird schwarz), °C, none = nie
#   ignites_at          Zündtemperatur mit Flamme in der Nähe, °C, none = brennt nicht
#   heat_of_combustion  Heizwert J/kg
#   burn_rate           Abbrand an der Oberfläche kg/(m²·s)
#   smoke               Rauch 0..1 (Holz wenig, Gummi viel und schwarz)
#   residue             Material, das nach dem Abbrennen liegen bleibt (Holz: charcoal), none = nur Asche
#   residue_share       Anteil des Volumens, der davon übrig bleibt 0..1
#
# REIBUNGSPAARE
#   [pair <a> <b>]  friction = Haft Gleit. a und b sind Materialnamen oder Klassen (wood, metal ...).
#   Zuerst gilt das Paar mit beiden Namen, dann eins mit Klassen, sonst der Mittelwert der Materialien.
