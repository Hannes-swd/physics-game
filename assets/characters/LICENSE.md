# Spielfigur

`worker.glb` – "Worker" aus dem *Ultimate Animated Character Pack* (November 2019) von **Quaternius**
(https://quaternius.com/packs/ultimatedanimatedcharacter.html), heruntergeladen über Poly Pizza
(https://poly.pizza/m/Yg2bQZO6Hj).

Lizenz: **CC0 1.0** (gemeinfrei) – https://creativecommons.org/publicdomain/zero/1.0/

Die Datei ist unverändert. Sie wird beim Bauen in das Programm eingebettet (`cmake/embed_file.cmake`).
Eine andere Figur im glTF-Binärformat (.glb, Skelett mit den Abläufen `Idle`, `Walk`, `Run`) kann sie ersetzen.
